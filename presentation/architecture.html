03 / System design
The architecture keeps product boundaries clear.
Each layer has one job, so the product can evolve from an offline demo into a production service without rewriting the experience.
Design principleKeep the interface stable while services and persistence evolve behind explicit boundaries.
01
Browser UI
English-first workspace with Arabic RTL support, account controls, chat history, and analytics.
02
Flask REST API
Protected routes derive user ownership from the server session rather than client-supplied IDs.
03
Service layer
Language detection and explainable response policy return intent, confidence, sentiment, and guidance.
04
SQLAlchemy + database
Users, reset tokens, conversations, feedback, and training data persist in SQLite locally or a configured production database.
4clear boundaries from user experience to persistence
Browser → API → services → data
